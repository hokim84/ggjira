# 0045. 기본 Agent 프롬프트 조회

## Context

PM과 구현 Agent의 지침이 코드에 있어 운영자가 웹 UI에서 확인할 수 없었다.

## Decision

관리자 인증을 적용한 GET /api/v1/admin/prompts와 웹 UI 프롬프트 메뉴를 제공한다.
실행에 쓰는 동일한 builder로 기본 지침과 합성 입력 예시를 생성하고 출력 스키마를 제공한다.
실제 이슈나 비밀정보를 읽지 않는다. 조회는 읽기 전용이며 프롬프트 편집 기능을 제공하지 않는다.

## Consequences

현재 Router 버전의 기본 지침을 확인할 수 있다. 과거 실행 스냅샷이나 CLI/저장소 지침을 포함한
전체 유효 입력을 의미하지 않는다. Worker 버전이 다르면 작업별 입력 형식도 다를 수 있다.
실행·승인·배정 정책과 Worker 프로토콜은 변경하지 않는다.
